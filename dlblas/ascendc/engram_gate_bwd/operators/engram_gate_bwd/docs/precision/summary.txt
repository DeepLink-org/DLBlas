## 诊断结论

### 问题类型分类

| 特征 | 类型 | 说明 |
|------|------|------|
| Tt=1 时 grad_k/wh/we 输出全 0 | **代码 bug** | RST({1, 512}) 归约行为异常，非精度问题 |
| 单核 Tt=4 所有梯度均超标 | **精度问题** | 算法数值敏感性 + bf16 输出 Cast 精度地板 |
| 多核 grad_wh/we 严重劣化 | **精度问题** | bf16 AtomicAdd 每核量化误差累积 |

### 根因层级

1. **一级根因**：bf16 Cast 输出量化（~0.4% 相对误差），所有梯度共享
2. **二级根因**：grad_wh/grad_we 多 tile + 多核累加使量化误差非抵消性累积
3. **三级根因**：DAV_2201 FP32 VECCALC 精度不足以在 15+ 步链式计算后保持 bf16 精度
4. **特殊根因**：Tt=1 时 RST 归约行为异常（代码级 bug，非精度问题）

### 推荐动作

1. 优先修复 Tt=1 RST bug（添加恒等映射快速路径）
2. 尝试 T_TILE=3（降低 VECCALC 压力至 85.3KB）
3. 尝试 fp32 AtomicAdd 替代 bf16 AtomicAdd（需额外 GM buffer）
4. 若仍不达标，终止 DAV_2201 路径，等待 DAV_3510 + RegBase
