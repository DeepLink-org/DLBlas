## Bottleneck Analysis
1. **Scalar-bound**: AIV scalar ratio ~98.5%, confirming the kernel is dominated by int64 scalar operations (mul/xor/mod)
2. **int64 mod is the main cost**: ~50 cycles per output element, dominated by the integer division (mod) operation
3. **Memory is not a bottleneck**: MTE2/MTE3 utilization < 2%, memory bandwidth far from saturation
4. **Vector unit unused (by design)**: Vector ratio ~0.02%, since DAV_2201 Vector unit does not support int64 arithmetic
5. **Multi-core scaling near ideal**: 47.78/48x = 99.5% efficiency, confirming load-balanced token splitting

## Conclusion
Performance is close to the physical ceiling for this scalar-bound integer hash kernel.
The ~50 cycles/element is dominated by int64 modulo (multi-cycle integer division) and cannot be avoided without breaking bit-exact correctness.
The kernel achieves excellent multi-core scaling (99.5% efficiency).
